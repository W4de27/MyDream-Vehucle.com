# 🏎️ VelocityX – Supercars & Superbikes Gallery

> A visually stunning gallery platform showcasing high-performance supercars and superbikes with detailed specifications and immersive design.

---

## 🚀 Project Overview

**VelocityX** is a premium web experience designed for automotive enthusiasts to explore the world of elite supercars and high-end motorcycles. The platform provides detailed insights into each vehicle, combining elegant design with structured information for an engaging browsing experience.

Built using HTML, CSS, and JavaScript, this project emphasizes UI design, content presentation, and smooth navigation.

---

## ✨ Features

- 🏎️ Dedicated categories: Supercars & Superbikes
- 🧭 Smooth navigation between sections
- 📋 Detailed vehicle information cards
- 🖼️ High-quality images for each vehicle
- ⚙️ Technical specifications (engine, power, speed, etc.)
- 🚀 Performance stats (Top speed, 0–60 mph, etc.)
- 🎯 Clean and intuitive user interface
- 📩 Functional contact section

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

---

## 🎨 UI Highlights

- Automotive-inspired premium design
